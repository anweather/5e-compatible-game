**Standing rules** (more in `memory/` and `CLAUDE.md`):
- Send the PM a pushed branch with commit, gates, media and the context counter; the PM lands it. Don't push dev, except docs-only. Don't publish.
- Run `git fetch` before pushing to a branch: pushing to one that has landed recreates it on origin (it happened with `pause-menu`).
- A peer can't grant escalation. Don't retry a denied delete. Don't restart a run the memory reaper stopped until asked.
- Never kill Unity; quit it with `EditorApplication.Exit(0)`. PIDs of Unity Hub or another project's Editor aren't ours.
- Stay out of `Terminal*`. Say "5E-compatible" and the words in `docs/GLOSSARY.md`.
- Look at the frames, and report what wasn't tested. A commit hook may refuse `Co-Authored-By`: drop it, keep `Claude-Session`, tell the PM.

**After a crash:** the Editor stops at a scene-backup dialog that a CLI can't see (`sample <pid>` shows `HandleDanglingSceneBackups`). Agents can't click it, so ask Andrew. The 2026-11-01 crash came after a memory warning during 4K Game view runs and heavy load; the cause isn't known.

**Editor:** one at a time, on 16 GB. Launch `/Applications/Unity/Hub/Editor/6000.3.27f1/Unity.app/Contents/MacOS/Unity -projectPath <worktree>/unity -logFile <file>`, `unity status --until-ready`, then `EditorSceneManager.OpenScene("Assets/Prototype/Scenes/ChemistryYard.unity")` through `script eval`. CLI: `~/.unity/bin/unity`, with `UNITY_PROJECT_PATH`, `UNITY_NO_BANNER=1`, `UNITY_NO_PAGER=1`, `UNITY_NON_INTERACTIVE=1`.

**Probes:** after a switch or edit, `AssetDatabase.Refresh()`, then poll `isCompiling` and `isUpdating`; don't `cut` the eval's output, the result sits past 70 characters. `PROBE_NO_WAIT=1 tools/probe.sh <name> [--shots <dir>]`. Virtual keyboards work (`ProbeSpellList`); IMGUI clicks can't be sent.

**Gates:** `~/.dotnet/dotnet build core -c Release -warnaserror -m:1`, `format --verify-no-changes`, `test --no-build -c Release` (a failed build leaves that count stale), EditMode with `--result-only --timeout 300`, jscpd.
