## How the Mac works (lessons from today)

- **Unity CLI:** `export PATH=$HOME/.unity/bin:$PATH UNITY_PROJECT_PATH=$PWD/unity`, then `unity command --timeout N
  script eval '<C#>'` (not `unity script eval`). Compile loop: `AssetDatabase.Refresh()`, poll
  `EditorApplication.isCompiling` until False, check `unity/Library/ScriptAssemblies/Assembly-CSharp.dll`'s time, then
  `unity command console status` for `"compilationFailed"`. The Editor runs one command at a time.
- **The nine:** build the yard on the valley only (no `unity/Temp/map`); write `nine` into `unity/Temp/map` just for a
  probe or Play run and remove it after. Building the yard with the nine selected left an unsaved scene and a hidden
  save dialog that hung the Editor for hours.
- **Full EditMode takes 40-48 min here.** Rebuild the yard first (`Prototype/Build Chemistry Yard`), run it in the
  background with `--timeout 3600`, and read `unity/Library/TestResults.xml` for the full list (the CLI's JSON is cut
  short). A run that times out at the CLI keeps going inside Unity; never enter Play meanwhile (its scene restore
  fails in Play, #174; probes now refuse during a run). After many Play runs, a test that reads a static can fail
  until `EditorUtility.RequestScriptReload()` (domain reload is off).
- **Player measurements:** `Prototype/Build/macOS (profiling)` builds a development player in about 3 min into
  `unity/Builds/macOSProfiling/`. Run it with `-logFile <log> -screen-fullscreen 0 -screen-width 1280 -screen-height
  720 -fps-probe -perf-offscreen -perf-scenario <fireball|meadow|bot|...> [-map nine]`, one at a time, and read
  `PERF RESULT`, `PERF MARKERS` (mean/worst per marker) and `PERF SPIKE`. The Mac's player is GPU-bound on the nine
  (~35 ms GPU), so compare markers, not whole frames.
- **Shell:** zsh arrays start at 1; save files before swapping versions for a before/after and restore with
  `git checkout HEAD -- <files>` from a commit, not from temp copies. Write C# for `script eval` into a file with a
  quoted heredoc to avoid quoting traps.
- **Commits:** the hook wants a subject of 50 characters or fewer; commit with `git commit -F -` and a heredoc.
- **The Mac is slow** partly from itself: Spotlight indexing `unity/Library`, `Temp` and `Builds`, and
  `mediaanalysisd`; the Editor had been up seven days. Andrew was told; restarting the Editor is his call.
