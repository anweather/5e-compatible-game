# Agent cost report, 2026-11-08

Data on dev, 2026-10-29 to 2026-11-08 20:45 (trailers start 2026-10-29). Units are ite (input-token equivalents:
input + 1.25 cache write + 0.1 cache read + 5 output). Compared with the 2026-11-06 report; "this period" is
2026-11-06 23:58 to 2026-11-08 20:45 (`features-since-2026-11-06.md`).

## Answer

- **Coordination is still over half of spend:** 145M of 265M ite this period (55%), up from 50% in the Nov 2-6
  period; 53% overall (488M of 914M). The lead session (this one, with unity-task subagents) is the biggest line.
- **Cache reads are 73% of feature cost** (70% last time): long sessions re-reading big contexts.
- **The PC is 4.7x the price of u2 per feature:** median 4.10M ite (host-ux) against 864k (u2); it was 2.2x.
  u2 built world-plan (3475 lines) for 1.46M and chunk-gen (1467 lines) for 607k; the PC's Editor features run 6-16M.
- **Size matters more now:** cost ~ lines^0.80 (was 0.20), r = 0.60. The fixed cost per task has shrunk: the queue,
  self-landing and short briefs are working.
- **Dearest this period:** castle-cliff-canyon 15.9M (437 min), unified-casting-view 13.4M (2096 min), maps-phase-6
  13.0M, wow-looks 10.5M, wow-spells 9.9M: all Editor work with looks judged by eye, 10-16k ite per line.
- **Issue telemetry is still broken:** every issue since about Oct 31 shows a discovery cost of 0, including the six
  the lead filed today (#169-174). Rediscovery was 18% while it worked (33 of 198 finds).

## Recommendations

1. **Move more work off the PC to u2** (targets the 4.7x): every core-only part of an Editor feature (generation,
   rules, data, measuring under `dotnet`) goes to u2 first, as world-plan, chunk-gen and test-speed-core did today; the
   PC gets only the compile, the look and the probes. Today's cell-memory step 1 (measure under dotnet) was PC work
   that u2 could have done.
2. **Shorter lead sessions, cleared after each batch of landings** (targets the 55%): the lead-handoff skill already
   writes STATE; clearing after each big batch drops the re-read context that drives cache reads.
3. **Looks judged once, by Andrew, from a board** (targets the 10-16k/line looks features): wow-looks, wow-spells and
   castle-cliff-canyon spent hours in the Editor iterating looks. Give options as clips or stills on a board in one
   round, as the casting and world sheets did.
4. **Put a `Discovery-Cost:` line on every issue the lead files** (fixes the zero): the lead's `gh issue create` calls
   today carried none. Add it to the unity-lead skill's issue step, or a wrapper that appends it.
5. **Give the Mac a commit hook:** none of its work (probe-speed, chunk-hash, roomopen-sync) carries trailers, so it is
   missing from every table here.

## Method

`feature-costs.mjs --ref origin/dev --overhead Coordinator,PM --sessions docs/telemetry/sessions.jsonl`, once for all
time and once `--since 2026-11-06`; `issue-costs.mjs --ref origin/dev`. A feature is a first-parent merge on dev (or a
commit straight on it); its cost is the trailers on the commits it brought in. Coordinator and PM lines are kept apart as
overhead.

## Findings

- **Overhead:** 22 commits this period carry only overhead (queue claims, briefs, STATE, J-080). The lead now does
  landings itself and its unity-task subagents' work is billed to the lead's session, not to the feature (a guess from
  the numbers: view-rebuild shows 407k ite and 5 min although its job ran about 40 min; cell-memory 3.0M and 33 min for
  a 47 min job). So part of the 55% is feature work in the wrong column.
- **Clusters:** small (median 153 lines, 418k ite, 48 min: test-speed-core, spell-balance, air-tuning-rules...),
  medium (353 lines, 2.8M: chunk-gen, cell-memory, world-plan, player-mods...), large Editor features (892 lines,
  9.9M, 207 min: maps-phase-6/7, casting-taps, wow-looks, wow-spells, peer-vanish, castle-cliff-canyon...). The large
  cluster costs 3.5x the medium for 2.5x the lines.
- **Cheap against the fit:** world-plan, chunk-gen, punchy-sync, air-tuning-rules (0.1x predicted), view-rebuild
  (0.2x, but see the overhead note). All but view-rebuild are u2's core work.
- **Issues:** 165 issues, 198 finds, 6k tokens per find where recorded. Fix first by discovery cost: #165 (the Hold
  offer, 2x, 150k), the storm and weather GPU set #27-#33 (84k each, 9 days open), #3 and #4 (50k). Most-found open
  issues with no cost recorded: #158 (shapeshift invisible, 3x), #156 (stamp steepness, 3x).
