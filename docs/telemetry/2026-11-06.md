# Agent cost report, 2026-11-06

Data on dev, 2026-10-29 to 2026-11-05 (trailers start 2026-10-29). Units are ite (input-token equivalents:
input + 1.25 cache write + 0.1 cache read + 5 output). Compared with the 2026-11-02 report.

## Answer

- **Coordination is half of all spend:** 330M of 626M ite (53%) overall; 50% since Nov 2 (was 55%). PM and coordinator sessions cost as much as every feature together.
- **Cache reads are 70% of feature cost** (66% on Nov 2): long sessions re-reading big contexts.
- **Time in the Editor, not code, makes features dear:** stamp-frame 517 min for 132 lines (36k ite/line), water-look-perf 369 min for 136 lines (34k), land-shapes 483 min. Median 5k ite/line.
- **Size barely moves cost:** cost ~ lines^0.20. Each task has a large fixed cost (median 1.6M ite), so tiny tasks are dear.
- **Linux VMs are half the price of the PC host:** median 1.0M ite per feature (u1, u2) against 2.2M (host-ux). Their account is down.
- **Issue telemetry has broken:** every issue filed since about Oct 31 has a discovery cost of 0. Rediscovery was 13% while it worked.

## Recommendations

1. **Restart the PM per batch, not per release, and keep it out of reading** (targets the 50%). Workers already take briefs from the mailbox; the PM should land with `land.sh auto` and the board script, and send reads to Haiku sub-agents.
2. **Split perf hunts into short fresh tasks** (targets cache reads and the 30k+/line outliers): one measure task, one fix task, each starting from a brief with the numbers, instead of one session that sits through Editor runs for 6-8 hours.
3. **Batch small changes into one brief** (exponent 0.20): 3 one-line fixes in one task cost about one task.
4. **Bring the Linux VMs back for core and rules work** (half the median cost) once their account is up.
5. **Fix the `Discovery-Cost:` line on new issues** (the PC's and Mac's issue filing): without it the fix-first list only ranks issues from before Oct 31.
6. **Give the Mac a commit hook**: its phase 5 and other work carries no trailers, so it isn't in these numbers.

## Method

`agent-cost-report` scripts on `origin/dev`, Coordinator lines as overhead, sessions.jsonl for work with no commit.
Full tables: `features-2026-11-06.md` (all), `features-since-2026-11-02.md` (this period), `issues-2026-11-06.md`, CSVs beside them.

## Caveats

- The Mac has no hook; merge commits double-count the host's work; Pro transcripts aren't on disk.
- Coordinator lines cover everything between merges, so they follow the clock, not the work.
- hold-hands shows 102k for 1476 lines: its code was written in another session, so it's mis-attributed, not cheap.
- Long features include waiting for the Editor, compiles and probes, not only thinking.
- 39 fixed issues cost 106M ite to fix; finding cost reads 0 for them because of the broken line.
