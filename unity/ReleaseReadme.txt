SPELL CHEMISTRY VALLEY  -  alpha {VERSION} ({COMMIT})
A 5E-compatible spell sandbox. This is an early alpha: expect rough edges,
missing pieces, bugs and the odd crash. Your saves, settings and the world
itself may change completely between versions.

RUNNING IT (Windows 10 or 11, 64-bit)
1. Unzip the whole folder somewhere (not inside the zip viewer).
2. Double-click SpellChemistryValley.exe.
3. The game isn't signed, so Windows may check it first. If Windows Security
   says "Scan required", let the scan finish (or click Scan) and it starts.
   If it says "The publisher could not be verified", click Run. If
   SmartScreen says "Windows protected your PC", click "More info", then
   "Run anyway". The first run may also ask to let it through the firewall:
   allow it for playing together.

CONTROLS (keyboard and mouse; a gamepad works too)
  WASD            move              Mouse        look
  Space           jump              Shift        sprint
  Mouse wheel     zoom
  1-8 or Q / E    choose a spell    Tab          next spell page
  Left click      cast
  E (near a thing) pick up / drop   F            use the held item
  G / right-click throw (hold to throw harder)
  R               reset the yard    Esc          menu
  M               the menu's Mods page (switch rules on and off)
With a controller, Start opens the menu: d-pad or left stick up / down to
move, A (Cross) to choose, B (Circle) to go back or close.
Spells mix: set grass alight, put it out with water, freeze the puddle,
grease a slope, blow smoke away. Try things.

PLAYING TOGETHER (up to 4 players, over the internet)
Everybody needs this same version (the Esc menu shows it at the bottom).
  Host:  Esc -> Play together -> Host online. Send your friend the code
         that appears (there is a Copy button).
  Join:  Esc -> Play together, type the code, click "Join code".
         With a controller: Start -> "Enter a code with the controller",
         then up / down to change each letter and A for the next (a code
         you copied is filled in already).
No accounts and no router setup are needed. If the join fails because the
versions differ, the game says so: both players download the newest alpha.

UPDATES
The game checks for a newer alpha when it starts. If there is one, the Esc
menu says so and has an "Open download page" button. Download the new zip
and unzip it next to (or over) this one.
All releases: https://github.com/anweather/5e-compatible-game/releases

REPORTING A BUG
Say what you did and what happened, and attach Player.log from
  %USERPROFILE%\AppData\LocalLow\anweather\Spell Chemistry Valley\Player.log
(Esc -> "Open log folder" opens that folder). The log is replaced each time
the game starts, so copy it before playing again.
